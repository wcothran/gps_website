Key rules

  • District result level → School Name stays at All.
  • School result level → select individual school(s).
  • Overall cannot be broken into student groups.
  • Low Sample Size = Yes when n ≤ 20.

Worked question

Compare Grade 4 Hispanic students’ ELA growth across elementary schools
  1. Select School result level.
  2. Select Lowest Performing 20%.
  3. Choose ES, ELA, Grade 4.
  4. Select the LEA and schools.
  5. Choose Race Five → Hispanic.
  6. Check every school’s student count.

Before sharing

  • Name the exact metric and filters.
  • Include the number of students.
  • Flag samples of 20 or fewer.
  • Verify chart labels and legends after export.
  • Describe the result before explaining it.
No data or an error? Open About this dashboard, confirm the combination is valid, clear all filters, and rebuild from the top.
