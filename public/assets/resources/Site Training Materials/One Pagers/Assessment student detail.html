Recommended filter order

Set year. Confirm enrollment year and assessment year.
Set place. Select district and school as needed.
Set test. Choose season, subject, and assessment.
Set result. Add performance level when the question requires it.
Set group. Add grade, ML/ELL, 504, special education, or other student group last.
WIN rule: Do not force a grade filter when the assessment assignment crosses grade levels. Select the relevant WIN assessments and applicable year instead.

Worked example

Question: Which ML/ELL students met or exceeded expectations on a fall formative assessment?
  1. Set year and district/school.
  2. Select Fall, assessment, and subject.
  3. Add grade if the test is grade-specific.
  4. Select ML/ELL status.
  5. Select Meets Expectations and higher bands.
  6. Review Filters Applied and export.
Multiple rows? The table is assessment-record level. One student may have multiple tests or seasons. Use Student ID to deduplicate when you need one row per student.

Before you export

  • Confirm every active filter.
  • Compare rows with unique Student IDs.
  • Check assessment and test date columns.
  • Keep Student ID in the working file.
  • Share student-level files only through approved systems.

Common recovery

If the list is empty or surprising: Clear all → set years → select assessment → add groups one at a time.
