Recommended filter order

Set the year. Clear all first if results look wrong.
Select assessment + subject. Keep the test definition consistent.
Select grade. Cut scores often differ by grade, though some exams pre-select grade.
Select season(s). Compare like administrations and see trends over time.
Add school or student group. Narrow only after the base slice is valid.
Grade rule: Do not combine grades when performance thresholds differ. ACT, SAT, WIN, and similar high-school assessments may use the assessment population instead.

Worked example

Question: What percentage of seventh graders met or exceeded expectations in spring compared with fall?
  1. Set year and district/school.
  2. Select one assessment and subject.
  3. Select Grade 7.
  4. Include Fall and Spring.
  5. Read performance level by season.
  6. Check counts before interpreting the difference.

Before you share a result

  • Write down every active filter.
  • Include the number of assessments or students.
  • Use View as table for exact values.
  • Say “the dashboard shows” before claiming why.
  • Use Student Detail for the follow-up roster.
Empty dashboard? Clear all, confirm the year, and rebuild the query from assessment to cohort. A stale year is a common cause.
