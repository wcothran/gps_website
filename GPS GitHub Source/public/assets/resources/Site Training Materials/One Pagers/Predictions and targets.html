What it is

The Predictions and Targets Dashboard shows how students are tracking toward their growth targets and — for the current year — predicts each student's summative score and likelihood of meeting that target, refreshed as interim results come in. Aggregate panels span district roll-up to a student-level prediction roster.

Two target types — set by the Target Type filter

AVT · Added-Value Target

The ambitious target
  • Set above typical growth (CGP 55–80)
  • Pushes students toward proficiency
  • Lower percent-met than MAT

MAT · Median Annual Target

The typical-growth target
  • Set at median (CGP 50) growth
  • The gain a typical similar student makes
  • Higher percent-met than AVT

Key terms

CGP — Conditional Growth Percentile
How a student's growth compares to similar peers. 50 = typical; higher = more growth.
Prediction Type
Current Best uses the latest interims; Beginning of Year uses prior summative only.
Pretest Score Type
State Equivalent Score is on the SC READY scale (comparable across tests); Scale Score is the test's own scale.

Quick steps

Sign in (portal.edanalytics.app)

SCDE/district Microsoft account (SSO).

Open Administrator Navigator

Launch the Administrator Navigator tile.

Open the dashboard

Left menu → Predictions and Targets (just below Growth).

Set filters & apply

School Year, School, Target Type, Subject, Prediction Type → click Apply Filters.

Read the headline

Percent Predicted card + the by-target-type and by-prior-proficiency charts.

Build a watch-list

Student table → Predicted to Meet Target = "no" rows → export via the three-dot menu.

Percent Met is empty until summatives arrive

Before the current year's SC READY summative, the Percent Met card shows No data. Predicted columns are populated in the meantime.

Good to know (from office hours)

No current-year scores? Set Prediction Type to Current Best, not Beginning of Year.

Exporting? Use Export to Excel — one row per student; CSV/pivoted repeat names.

No high schoolers — only elementary/middle grades have targets.

Predictions are current-year only; past years show only percent met.

Only students with a target appear, so counts can be below enrollment.
