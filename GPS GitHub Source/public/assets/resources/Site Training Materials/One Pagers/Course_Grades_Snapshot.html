Recommended filter order

Year & place. School Year, then District/School — leave School blank for a full district view.
Course. Select the course(s) you want to grade-check.
Grading Period & Grade Type. Choose S1, S2, or both — and set Grade Type to Final Grade.
Grade Level. Leave blank for all grades district-wide, or select specific grade(s) to compare across the district.
Numeric Range. Use the scroller to set the cutoff — see callout below.
Scroller, not a typed field. "Select Numeric Range" doesn't reliably take typed values — drag the small scroller handles instead. For district-wide B-or-higher, scroll to 80–100.
Grade Type: lock in on Final Grade. Grade Type is fed from PowerSchool store/score codes and can look cryptic in the filter list. Final Grade (often coded F1) is the stable end-of-period value — use it as your standard. Exam-period codes (e.g., X1) may reflect exam-only grades and will shift what you're reading.

About this Dashboard

Before filtering, open the "About this Dashboard" tab and summarize the key facets out loud — invite the room to read it themselves later rather than reading it to them line by line.

Worked example

Question: What percentage of district students scored a B or higher in English 2, Semester 1?
  1. Set School Year; leave District selected and School blank.
  2. Select course: English 2.
  3. Set Grading Period to S1; Grade Type to Final Grade.
  4. Scroll the Numeric Range to 80–100.
  5. Read the summary panel for the matching percentage and count.

Letter grade vs. numeric grade

LetterGradeEarnedText / string field
NumericGradeEarnedDecimal / float field

Both exist because instructors record grades differently: the model supports one-time standards (e.g., a student learns to count to 10) as well as standards graded multiple times across a school year.

Before you export

  • Confirm Grade Type is set to Final Grade, not an exam-period code.
  • Note the student count the summary panel shows.
  • Right-click → Download to keep your filters in the export — a plain download drops them.
  • Carry the filter definition with anything you share.
Empty or surprising result? Clear all, reset Grade Type to Final Grade, and re-check that Grading Period matches what you intend (S1 alone ≠ S1 and S2 together).
