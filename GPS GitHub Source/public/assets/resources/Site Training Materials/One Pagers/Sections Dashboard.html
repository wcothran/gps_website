Course: select every relevant local name

Four common questions

Highest chronic absence by sectionSelect schools + session → Highest Count → Section tab.
All Algebra II studentsSelect all Algebra II course names → Student Table → export.
Students taught by one educatorSelect educator → Section Information → Student Table.
AP Calculus race/ethnicitySelect all AP Calculus names → Section Detail → composition charts.
Interpret rankings carefully. A listed section or educator serves students who meet the condition. The chart does not show where an incident occurred or who made a referral.

Before exporting

  • Confirm every active filter.
  • Check the visible row and record counts.
  • Review Current Enrollment Status.
  • Hide fields that are not needed.
  • Use Student ID in working rosters.
  • Carry the filter definition and export date with the file.

Two facts to remember

Chart clicks filterClick a bar only when you intend to narrow the dashboard.
Exports are filteredCSV and Excel downloads reflect the active scope.

Reset between questions

Chart and table filters can remain active. Clear the old context, then rebuild from year and place when starting a different scenario.
